# Dhananjayan's Portfolio

A modern, responsive portfolio website showcasing AI/ML engineering skills and projects.

## Features
- Responsive design
- Smooth scrolling navigation
- Project showcase
- Skills section
- Contact information

## How to Deploy to GitHub Pages

1. Create a new repository on GitHub named `dhananjayan-aiml.github.io`
2. Upload all files from this portfolio folder to the repository
3. Go to repository Settings → Pages
4. Set source to "Deploy from a branch" and select "main"
5. Your site will be available at `https://dhananjayan-aiml.github.io`

## Customization

Update the following in `index.html`:
- Replace placeholder text with your actual information
- Add your real project details
- Update contact links with your actual profiles
- Add your email address

## Local Development

Simply open `index.html` in your browser to preview the site locally.
